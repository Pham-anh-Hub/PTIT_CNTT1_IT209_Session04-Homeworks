# Bài tập 1:

## Các cấu hình đã sử dụng: 

### 1. cấu hình email cục bộ:
```bash
git config --local user.email
```

### 2. Cấu hình tên cục bộ:
```bash
git config --local user.name
```

### 3. Kiểm tra & xem lịch sử commit (edited):
```bash
git log --oneline
```
